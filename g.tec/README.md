# g.tec Unicorn Hybrid Black

> 🚨 **DO NOT CLOSE THE UNICORN HYBRID BLACK APP** — the license will disappear (known bug).

## Installation
- Install [Unicorn Suite](https://www.gtec.at/product/unicorn-suite/).
- **Do not activate the license yourself** — a g.tec representative activates it on site.
- **Windows** is the safest OS. On Linux / macOS use [g.Pype](https://gpype.gtec.at/) (`pip install gpype`) — it supports the Unicorn on newer systems but is less tested.
- macOS / Linux-only teams: **BCI Core 4/8** (works with g.Pype without a license) is the better alternative — assigned after consultation with the organizers.

## Signal preview
**Unicorn Recorder** — shows the signal and also streams it over LSL.

## Accessing data
- Python API: https://github.com/unicorn-bi/Unicorn-Hybrid-Black-Windows-APIs
- g.Pype: https://gpype.gtec.at/
- Unity: https://github.com/unicorn-bi/Unicorn-Hybrid-Black-Unity-Interface
- **Unicorn Bandpower (UDP)** / **Speller (P300, UDP)** — the fastest route to games and art projects.

## Troubleshooting
### UDP packets don't arrive
- Check that the IP address and port match
- Check the Windows firewall
- Make sure sender and receiver are on the same machine or the same network

First ask our technical staff or the g.tec representatives on site.
You can also post on the g.tec Discord (help channel): https://discord.gg/b45kR9cbf — teams can ask g.tec directly.
